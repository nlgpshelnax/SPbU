## 🎯 Что внутри

Все темы объяснены **с полного нуля** до уровня отличной сдачи экзаменов и коллоквиумов:
- **Никаких доказательств в одну строчку**: все формулы и теоремы расписаны шаг за шагом со всеми алгебраическими и логическими переходами.
- **Вводный ликбез и кванторы перед каждой темой**: разбор кванторов ($\forall, \exists, \exists!$), логики, терминов и ментальных моделей («на пальцах») до начала сложных выкладок.
- **Интерактивные доказательства**: 92 блока доказательств оформлены через `<details class="proof-box">` — их можно разворачивать для изучения или сворачивать кнопкой «🎓 Экзамен» для самопроверки.
- **Высокая производительность (120 FPS)**: поддержка `content-visibility: auto`, пассивные обработчики скролла и ленивая подгрузка формул KaTeX через `IntersectionObserver`. Вёрстка плавная на компьютерах и смартфонах.

## 🛠️ Сборка из исходников

Если вы хотите внести изменения в Markdown-файлы в папке `Super_Textbook/`, пересобрать портал можно одной командой:

```bash
python3 build_textbook.py
```

Скрипт автоматически преобразует Markdown, компилирует оглавление, размечает интерактивные доказательства и генерирует готовый `index.html`.
