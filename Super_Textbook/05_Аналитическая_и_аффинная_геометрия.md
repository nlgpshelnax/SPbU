# Глава 1. Аффинные пространства и аксиоматика Вейля

## 🧭 Ликбез и ментальные модели
> [!IMPORTANT]
> **Векторное vs Аффинное пространство**:
> - В **векторном пространстве** $V$ есть выделенный «центр Вселенной» — нулевой вектор $\vec{0}$. Любой вектор «помнит», откуда он растет.
> - В **аффинном пространстве** $\mathbb{A}$ все точки абсолютно равноправны — начала координат нет!
> - Но между любыми двумя точками $A, B \in \mathbb{A}$ можно провести вектор перемещения $\overrightarrow{AB} \in V$.
> - Операция: «Точка + Вектор = Новая Точка» ($A + \vec{v} = B$).
> - Операция: «Точка - Точка = Вектор» ($B - A = \overrightarrow{AB}$).
> - Операция: «Точка + Точка» в общем случае **не имеет смысла** (за исключением барицентрических комбинаций с суммой весов 1)!

---

### Строгие аксиомы Вейля (Hermann Weyl, 1918)
Пусть $V$ — векторное пространство над полем $K$.
Непустое множество $\mathbb{A}$ называется **аффинным пространством**, ассоциированным с векторным пространством $V$, если задано отображение:
$$\phi: \mathbb{A} \times \mathbb{A} \to V, \quad (A, B) \mapsto \overrightarrow{AB}$$
удовлетворяющее двум аксиомам:

1. **Аксиома откладывания вектора**:
   Для любой фиксированной точки $A \in \mathbb{A}$ и любого вектора $\vec{v} \in V$ существует **и единственна** точка $B \in \mathbb{A}$ такая, что:
   $$\overrightarrow{AB} = \vec{v}$$
   (Эту точку обозначают $B = A + \vec{v}$).

2. **Аксиома треугольника (Правило Шаля / Chasles' identity)**:
   Для любых трёх точек $A, B, C \in \mathbb{A}$:
   $$\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$$

---

### Фундаментальные следствия из аксиом Вейля
> [!NOTE]
> **Теорема 1.1**:
> 1. $\forall A \in \mathbb{A}: \overrightarrow{AA} = \vec{0}$.
> 2. $\forall A, B \in \mathbb{A}: \overrightarrow{BA} = -\overrightarrow{AB}$.
> 3. $\forall A, B, O \in \mathbb{A}: \overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$.

##### 📝 Строгие доказательства:
1. По аксиоме треугольника при $B = A, C = A$:
   $$\overrightarrow{AA} + \overrightarrow{AA} = \overrightarrow{AA}$$
   Прибавляя в векторном пространстве $V$ вектор $-\overrightarrow{AA}$ к обеим частям: $\overrightarrow{AA} = \vec{0}$.
2. По аксиоме треугольника при $C = A$:
   $$\overrightarrow{AB} + \overrightarrow{BA} = \overrightarrow{AA} = \vec{0} \implies \overrightarrow{BA} = -\overrightarrow{AB}$$
3. По аксиоме треугольника для точек $O, A, B$:
   $$\overrightarrow{OA} + \overrightarrow{AB} = \overrightarrow{OB} \implies \overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} \quad \blacksquare$$

# Глава 2. Аффинный репер и преобразование координат

### 1. Аффинный репер
**Аффинным репером** в $n$-мерном аффинном пространстве $\mathbb{A}^n$ называется набор:
$$\mathcal{R} = (O, \, e_1, e_2, \dots, e_n)$$
где:
- $O \in \mathbb{A}$ — фиксированная точка (начало координат);
- $(e_1, e_2, \dots, e_n)$ — базис ассоциированного векторного пространства $V$.

Для любой точки $M \in \mathbb{A}$ её радиус-вектор $\overrightarrow{OM}$ однозначно раскладывается по базису:
$$\overrightarrow{OM} = x_1 e_1 + x_2 e_2 + \dots + x_n e_n$$
Набор чисел $(x_1, \dots, x_n)^T$ называется **аффинными координатами точки $M$** в репере $\mathcal{R}$.

---

### 2. Замена аффинного репера
Пусть дан старый репер $\mathcal{R} = (O, e)$ и новый репер $\mathcal{R}' = (O', e')$.
Пусть координаты нового начала $O'$ в старом репере равны $X_0$: $\overrightarrow{OO'} = e X_0$, а новый базис выражается через старый матрицей перехода $C$: $e' = e C$.

> [!NOTE]
> **Теорема 2.1 (Формула преобразования координат)**:
> Если точка $M$ имеет координаты $X$ в репере $\mathcal{R}$ и $X'$ в репере $\mathcal{R}'$, то:
> $$X = C X' + X_0$$

##### 📝 Доказательство:
$$\overrightarrow{OM} = \overrightarrow{OO'} + \overrightarrow{O'M} = e X_0 + e' X' = e X_0 + (e C) X' = e(C X' + X_0)$$
В силу единственности координат вектора в базисе $e$: $X = C X' + X_0$. $\blacksquare$

# Глава 3. Аффинные комбинации и барицентрические координаты

### 1. Корректность барицентрической комбинации точек
Пусть $P_1, P_2, \dots, P_k \in \mathbb{A}$ — точки, а $\lambda_1, \lambda_2, \dots, \lambda_k \in K$ — скаляры.
Определим точку $X$ через точку отсчёта $O$:
$$\overrightarrow{OX} = \sum_{i=1}^k \lambda_i \overrightarrow{OP_i}$$

> [!NOTE]
> **Теорема 3.1**: Точка $X$ не зависит от выбора вспомогательной точки $O$ тогда и только тогда, когда:
> $$\sum_{i=1}^k \lambda_i = 1$$

##### 📝 Полное строгое доказательство:
1. Выберем другую точку отсчёта $Q \in \mathbb{A}$.
   Тогда для каждой точки $P_i$: $\overrightarrow{OP_i} = \overrightarrow{OQ} + \overrightarrow{QP_i}$.
2. Подставим это выражение в формулу для радиус-вектора:
   $$\overrightarrow{OX} = \sum_{i=1}^k \lambda_i (\overrightarrow{OQ} + \overrightarrow{QP_i}) = \left(\sum_{i=1}^k \lambda_i\right) \overrightarrow{OQ} + \sum_{i=1}^k \lambda_i \overrightarrow{QP_i}$$
3. С другой стороны, по правилу вычитания $\overrightarrow{OX} = \overrightarrow{OQ} + \overrightarrow{QX}$. Приравниваем:
   $$\overrightarrow{OQ} + \overrightarrow{QX} = \left(\sum_{i=1}^k \lambda_i\right) \overrightarrow{OQ} + \sum_{i=1}^k \lambda_i \overrightarrow{QP_i}$$
   $$\overrightarrow{QX} = \left( \sum_{i=1}^k \lambda_i - 1 \right) \overrightarrow{OQ} + \sum_{i=1}^k \lambda_i \overrightarrow{QP_i}$$
4. Чтобы вектор $\overrightarrow{QX}$ (а значит, и само положение точки $X$) не зависел от выбора точки $O$, коэффициент при $\overrightarrow{OQ}$ обязан тождественно равняться нулю:
   $$\sum_{i=1}^k \lambda_i - 1 = 0 \iff \sum_{i=1}^k \lambda_i = 1$$
Точка $X = \sum_{i=1}^k \lambda_i P_i$ корректно определена! $\blacksquare$

---

### 2. Барицентрические координаты в треугольнике и симплексе
Пусть $A, B, C$ — три аффинно независимые точки на плоскости (вершины невырожденного треугольника).
Тогда любая точка $P$ плоскости однозначно представима в виде:
$$P = \alpha A + \beta B + \gamma C, \quad \alpha + \beta + \gamma = 1$$
Числа $(\alpha, \beta, \gamma)$ называются **барицентрическими координатами** точки $P$.

> [!NOTE]
> **Теорема 3.2 (Геометрический смысл через ориентированные площади)**:
> $$\alpha = \frac{S_{\triangle PBC}}{S_{\triangle ABC}}, \qquad \beta = \frac{S_{\triangle PCA}}{S_{\triangle ABC}}, \qquad \gamma = \frac{S_{\triangle PAB}}{S_{\triangle ABC}}$$

- Точка $P$ лежит строго внутри треугольника $\iff \alpha > 0, \beta > 0, \gamma > 0$.
- Центр масс (центроид) треугольника: $(\frac{1}{3}, \frac{1}{3}, \frac{1}{3})$.
- Центр вписанной окружности (инцентр): $(\frac{a}{a+b+c}, \frac{b}{a+b+c}, \frac{c}{a+b+c})$, где $a, b, c$ — длины сторон.

# Глава 4. Аффинные подпространства и взаимное расположение

### 1. Аффинные подпространства
Подмножество $L \subseteq \mathbb{A}$ называется **аффинным подпространством** размерности $k$, ассоциированным с линейным подпространством $U \le V$ ($\dim U = k$), если существует точка $P_0 \in L$ такая, что:
$$L = P_0 + U = \{P_0 + \vec{u} \mid \vec{u} \in U\}$$
Подпространство $U$ называется **направляющим подпространством** (direction space) для $L$.

### 2. Взаимное расположение двух аффинных подпространств
Пусть $L_1 = P_1 + U_1$ и $L_2 = P_2 + U_2$.
1. **Пересекаются**: $L_1 \cap L_2 \neq \emptyset \iff \overrightarrow{P_1 P_2} \in U_1 + U_2$.
2. **Параллельны**: $L_1 \cap L_2 = \emptyset$ и либо $U_1 \subseteq U_2$, либо $U_2 \subseteq U_1$.
3. **Скрещиваются**: $L_1 \cap L_2 = \emptyset$ и ни одно из направляющих подпространств не содержится в другом ($U_1 \not\subseteq U_2$ и $U_2 \not\subseteq U_1$).
